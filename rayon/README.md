# Villa Coral — parametric house after Ummahat 9-3 (Kengo Kuma & Associates)

Rayon model: **SIPEF PLAN MASSE** (`f0639f43-30b8-4bad-8e58-fa072abb77e1`), canvas `3D canvas`, layer
`Villa Coral (réf. KKAA Ummahat) – paramétrique`. Second 20 × 20 m plot placed 6 m east of the existing `Site 20x20 m`.

Reference: Capitude (Supabase `capitude`) project `ref-kkaa-ummahat-9-3` — KKAA 1-BED-CORAL plan 1:100,
ArchDaily sheets 29–31 (Coral sections / elevations), aerial photos.

- `villa_ummahat_parametric.ts` — generator (run with Rayon `run_typescript`): spiral shell roof (u/v surface,
  310° wrap, oculus, slot over pool), deck on Ø300 piles at +2.00, pool, stair, radial joists, rafters,
  timber fan, clerestory, claustra. All dimensions in `P` (plan scaled ×0.93 from KKAA so the Ø19.2 m roof fits the plot).
- Native BIM elements were then added in Rayon: levels +2.00 / +5.00, faceted & curved native walls, hosted doors/windows,
  rooms (zones), sections A-A / B-B, South / East elevations, plan and roof plan views, 5-page A3 deck at 1:100.
- `villa_coral_cover_fal_NE.png` — cover image (fal.ai nano-banana edit of the Rayon NE camera view).
